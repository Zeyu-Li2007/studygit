# studygit

练习 Git 用的仓库。

## 常用命令速查

```bash
git status              # 查看当前改动
git add .               # 暂存所有改动
git commit -m "说明"     # 提交
git push                # 推送到 GitHub
git pull                # 拉取远端更新
git log --oneline       # 查看提交历史
```
